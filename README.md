# 🎮 Game UI Design: Echoes of Lumé

Conceito de interface para launcher de jogo no estilo fantasia/RPG, desenvolvido no Figma com base na estrutura de UI do client de *League of Legends*.

---

## 📌 Visão Geral
Recriação e adaptação de uma interface de jogos (*Game UI*), focando em hierarquia visual, ambientação temática e disposição de elementos de navegação (botões de ação, carrossel de personagens e barra de progresso).

---

## 🛠️ Tecnologias & Ferramentas
* **Figma:** Vetorização, tipografia temática, botões de ação e composição de layout.
* **IA Generativa:** Criação de artes conceituais e elementos visuais de fundo/personagem.
